# League Vector Model Limitations

The proprietary projection engine is not yet a production model.

Current limitations include incomplete source-by-source licensing review, no finalized historical training dataset, no calibrated uncertainty model, no validated rookie pipeline, incomplete confirmation of legally usable participation/pressure data for IDP, and no evidence yet that any League Vector model beats simple baselines or commercial providers.

SportsDataIO free-trial values are scrambled and are excluded from training truth. Sleeper's undocumented projection endpoint is unstable and is not approved as a production dependency.

Any future projection must identify missing inputs and scoring categories it cannot support. Confidence must be statistically calibrated or labeled as a heuristic. Model performance claims require temporal backtests using data available at the original prediction date.
