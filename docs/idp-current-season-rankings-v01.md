Status: **READY FOR QA / HIGH — experimental current-season ranking only**

Parent research checkpoint: PR #20 head `e6423f31bd841696b0fc576080f9e89be04e815f`.

This candidate intentionally separates:

- **A. Current-season IDP projection / surplus ranking** — candidate for user-visible experimental integration.
- **B. Multi-year IDP Dynasty Value** — still blocked.

The permanent firewall remains `idp_dynasty_value_available=false`.

## Eligibility contract

User-visible candidates must pass the PR #20 fail-closed current Sleeper eligibility gate. The latest executed foundation evidence retained 753 safely current-rostered projection-ready IDPs: DL 278, LB 222, DB 253. It excluded 994 stale/unsafe records, including 838 teamless Active records that could not be independently verified, 25 injury-status records without a team, and 131 explicit Inactive records.

No retired, inactive, missing-current-identity, or unverified teamless player may enter the ranking candidate.

## Hybrid contract

`primary_position` is the single historical modeling family (DL/LB/DB).

`eligible_positions` is the full current Sleeper lineup eligibility after canonicalization. Examples from the latest live audit include 47 DL/LB players and 1 DB/LB player.

A hybrid is scored once. Starter/replacement allocation is one global constrained assignment across dedicated DL/LB/DB and IDP FLEX slots. A player may fill at most one slot. League Vector never computes independent DL and LB values and chooses whichever is larger.

## League scoring contract

`projected_points` is the player's projected current-season IDP stat line scored directly under `league.scoring_settings`.

Supported projected categories are:

- total tackles
- solo tackles
- assisted tackles
- tackles for loss
- sacks
- QB hits
- interceptions
- passes defended
- forced fumbles
- fumble recoveries
- defensive touchdowns
- safeties

If the league has a meaningful active IDP scoring key outside this supported vocabulary, the candidate fails closed instead of ranking on a knowingly incomplete subtotal. If an active supported scoring key requires a projected stat that is missing for a player, that player is not rankable.

`scoring_coverage` exposes supported keys, unsupported keys, and missing projected stats.

## League structure contract

League size comes from `total_rosters` and starter demand comes from `roster_positions`.

Canonical dedicated groups:

- DL: DL / DE / DT / EDGE
- LB: LB / ILB / OLB
- DB: DB / CB / S / FS / SS
- shared flex: IDP_FLEX

Unknown IDP-like starter slots fail closed rather than being silently treated as another position.

## Frozen current-season replacement definition

For each exact eligibility set, League Vector adds a synthetic additional player with that eligibility and solves the full league IDP starter assignment. Binary search determines the minimum projected points at which that additional player enters the optimized starter pool.

That value is `league_replacement_points`.

Examples of different eligibility sets are `DL`, `LB`, `DB`, `DL/LB`, and `DB/LB`. A hybrid therefore receives the replacement threshold generated by its exact eligibility set, not `max(DL replacement, LB replacement)` or another hand-picked positional rule.

The method uses only:

- league size;
- dedicated starter counts;
- IDP FLEX count;
- current verified player eligibility;
- league-scored projected points.

There are no universal positional replacement constants.

## Current-season surplus

`projected_surplus = projected_points - league_replacement_points`.

This is a **one-season lineup scarcity quantity only**. It is explicitly not Dynasty Value and contains no age multiplier, multi-year horizon, market anchor, role-survival multiplier, or offense/IDP normalization.

A player can have negative projected surplus while still remaining visible in a points ranking. Core/UI may sort by projected points or projected surplus but must label surplus as current-season projected surplus / points above replacement.

## Required UI language

Allowed labels include:

- Experimental IDP Current-Season Rankings
- Projected 2026 IDP Points

- Role confidence: limited

Disallowed labels include:

- IDP Dynasty Value
- Dynasty IDP Rankings
- Combined Dynasty Rankings

unless a later independently QA-approved dynasty model exists.

## Why current-season can advance while Dynasty Value stays blocked

The current-season calculation requires current eligibility, current projected stat output, actual league scoring, and current league lineup scarcity. Those contracts now exist and are testable.

True multi-year dynasty valuation still requires defensible age-survival, historical opportunity/role survival, multi-year surplus integration, and uncertainty calibration. PR #20's executed 2015-2025 research produced zero defensive-snap player-season rows from the normalized source, so true historical starter/reserve role survival remains blocked.
